# ExM-Upgrade 2.0

1) Выход из машины, возможность угнать любую машину. (доступно при новой игре+)
2) Меню доступное в любой момент по кнопке.
3) Тюнинг техники (Скаут, Урал, Молоковоз, Миротворец, Вэн.)
4) 4 Мини-игры доступные если выпить ананаги с Витей.
5) Техника из Zil Mod и Extra Machines.
6) Оружие для тарана.
7) Изменение сюжетных квестов по ветке без Лисы на первых четырёх картах.

9) Усложнены боссы Ньери и Оракул.
10) Теперь доступны только 3 сложности на выбор.
11) При выборе любой сложности игры, помимо прицеливания и увеличения урона, у ботов и игрока будут меняться характеристики тарана и урона от оружия.
12) 3 новые концовки. Можно: Проиграть Оракулу (Канонична Меридиану); Убить Лису (тупиковая); Отомстить убийцам на базе безумцев (Каноничная для ветки с Лисой);
13) Загадка в центре развлечений изменилась.
14) Гонки в Риджине.
15) Огромное количество новых боёв в колизее, которые открываются по мере прохождения сюжета. Вы можете сразиться с Демовцами на их любимых билдах. А именно с: Павлик RPG, OverLine, Gnome627, _nEmPoBu4__, стакан, MasterOk.
16) Коллизия большинства домов была исправлена.
17) Добавлен камикадзе в базу безумцев.
18) Various Hack позволяющий чиниться и заправляться товарами как в меридиане, а также несколько фиксов от него.
19) Секретная концовка в Кайо-Мерико была переделана. Условие получения изменилось, необходимо пройти игру на 100%.
20) Новая игра+ (Доступно в меню при прохождении игры до конца).
21) Новые случайные события.
22) Рпг диалоги в первом регионе.
23) Исправление найденых проблем в 1.1.2. (Софтлок по ветке с Лисой. Квест с проездом по бандитскому мосту при его подрыве оставался и др.)
24) Изменены цены на некоторую технику.
